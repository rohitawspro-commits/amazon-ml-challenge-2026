# Rohit Pujari · Portfolio

Static site: `index.html` + `assets/`. No build step.

## Deploy on Vercel
1. Push this folder to a GitHub repo (or keep it in a subfolder).
2. On vercel.com: **Add New → Project → Import** the repo.
3. Framework preset: **Other**. Root directory: this folder. Build command: none. Output directory: `.`
4. Click **Deploy**.

Or with the CLI from this folder: `npx vercel --prod`.
